# codex/

給外部模型（Codex、Antigravity CLI）覆核用的規劃文件。

**這裡的東西不是本專案的正式產物。** 專案的規格與變更提案一律在 `openspec/`，
第一階段的調查報告在 `docs/`。本資料夾放的是**還沒進入 Spectra 流程的構想**——
寫下來是為了能整份交給外部模型獨立判斷，而不是口頭轉述我的摘要。

規則：

- 這裡的文件**不具權威性**。任何一項要真的動工，仍須走 `/spectra-propose`，
  以 `openspec/changes/` 的 artifacts 為準。
- 文件應寫成「可被反駁的形式」：主張、依據、以及我自己知道的弱點。
  只寫結論而不寫依據的文件，外部模型無從查證，等於白寫。
- 引用 repo 內的檔案時給路徑，讓覆核者能自己去讀，不必相信文中的轉述。
