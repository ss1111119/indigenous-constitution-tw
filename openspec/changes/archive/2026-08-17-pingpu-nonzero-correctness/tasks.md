## 1. 非零平埔的測試樣本

- [x] 1.1 依 design 的「非零平埔樣本的構造方式」，建立 pingpu-registered 回歸樣本，使兩個來源同時自洽：ODRP013 的山地、平地、平埔三者相加等於原住民合計；ODRP018 主清單 16 現行族＋10 平埔族群＋未申報相加等於同一個合計。平行的平埔交叉表欄位刻意給與主清單不同的值，使誤讀交叉表的實作會失敗而非碰巧通過。驗證方式：以該樣本執行轉檔，確認離開碼為 0 且四份 processed JSON 產出。

- [x] 1.2 「Regression tests cover a period with registered plains-indigenous people」的三個 Scenario 成為可執行斷言：轉檔成功並產出檔案、兩組加總恆等式在非零平埔下成立、平埔數值確實出現在產出檔中。斷言須具體到數值而非僅檢查欄位存在：人口檔的平埔欄位全國合計等於樣本預期值、族別檔十個平埔族欄位合計等於同一預期值、兩者與原住民合計對得上、且交叉表與主清單的差額沒有出現在任何產出檔中。驗證目標：`pwsh tests/run-regression.ps1` 的離開碼與新增案例的斷言列，且既有四組樣本（success、tribe-sum-mismatch、pingpu-double-count、amplitude-jump）結果不變。

## 2. 席次模擬器的人口基數

- [x] 2.1 依 design 的「基數公式改為先扣除已登記平埔再加滑桿值」，滿足 Start from the status quo 對不重複計算的要求：模擬器計算的原住民人口在任何滑桿值下都不重複計算已登記平埔人口。滑桿歸零時報出的人口等於官方原住民總數扣除已登記平埔；滑桿等於已登記數時等於官方原住民總數。驗證方式：以 delta spec 的 base arithmetic 表四列為測試案例逐列比對計算結果。

- [x] 2.2 依 design 的「現況起點由資料導出而非常數」，滿足 Start from the status quo 的初始狀態要求：模擬器初始狀態重現官方現況：滑桿預設值取自載入資料的平埔人口欄位，而非寫死的 0。平埔為 0 的資料下，畫面與變更前完全相同。驗證方式：分別以平埔為 0 與非零的資料載入，確認初始報出的原住民人口等於該份資料的官方原住民總數。

- [x] 2.3 滿足 Population slider bounds are declared as reference points：滑桿的官方參考點標示與說明文字改由資料導出，不再宣稱登記數為零，除非資料確實為零。驗證方式：以非零平埔資料檢視，確認參考點位置與標籤文字皆為該筆資料的數值；並以搜尋確認原始碼中不存在以平埔人口數值書寫的現況陳述。

- [x] 2.4 依 design 決策「現況判定與滑桿零點是兩件事」，現況標示改以滑桿等於已登記平埔人口為準，而非等於零。平埔非零時初始畫面須被標示為現況；滑桿拉到零時不得標示為現況。人口比例的現況基準仍使用官方原住民總數（已含平埔），不改用扣除後的基數。驗證方式：以非零平埔資料載入，檢查初始標題與滑桿歸零後的標題各為何。

- [x] 2.5 依 design 決策「動態官方參考點必須同時動態化其溯源」，參考點的數值、位置與標籤文字皆由資料導出，並掛上來源識別、欄位性質與期別，與站台其他數字的溯源方式一致。不得保留寫死的期別描述。驗證方式：以非零平埔資料檢視參考點，確認其溯源資訊指向載入資料的來源與期別。

- [x] 2.6 依 design 決策「滑桿級距與已登記數可能不對齊」，已登記數非千人倍數時初始值仍正確呈現，畫面數字與官方數字一致。驗證方式：以三位數的已登記平埔值（例如 846）載入，確認滑桿初始顯示值與模擬器報出的人口皆未被級距調整。

## 3. 人口面板的敘述

- [x] 3.1 依 design 的「頁尾敘述明確涵蓋範圍」，滿足 Tribe composition statements name what they cover 的加總敘述要求：合計敘述指明其涵蓋圖表中的各族、未申報、以及圖表下方獨立區塊的平埔族群，使該句在平埔以獨立區塊呈現且數值非零時仍然正確。不改動加總本身。驗證方式：以 delta spec 的兩列表格（平埔為 0 與 846）比對敘述文字與所述總數。

- [x] 3.2 依 design 決策「移除「首次」的時序宣稱」，同屬 Tribe composition statements name what they cover 的無先後主張要求：已登記狀態的敘述不再宣稱該期為官方統計中首次出現平埔登記人口。驗證方式：以非零平埔資料檢視該區塊文字，確認不含先後主張；並確認移除後的敘述仍說明這些是官方統計中的平埔登記人口。

- [x] 3.3 依 design 決策「移除「首次」的時序宣稱」的連帶清理，溯源模組中以「平埔族群首次出現非零值」為例的說明註解不再指向已移除的敘述。驗證方式：內容審閱，確認註解所舉的例子仍與程式碼實際行為相符。
