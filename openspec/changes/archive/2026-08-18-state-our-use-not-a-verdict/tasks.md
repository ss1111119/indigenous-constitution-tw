## 2. 目錄頁的呈現

- [x] 2.1 依 design 決策「授權是否明確由資料判定，不由人工逐筆標記」，滿足 Licence grant and this project's reuse judgement are shown as separate facts 的導出要求：頁面由 `license` 欄位的內容判定該筆是否為明確開放授權，不新增第二個需人工維護的旗標；授權名稱無法辨識者歸入需要當心的一側。驗證方式：以搜尋確認登記檔未新增任何「是否明確」的布林欄位；並以一筆虛構的未知授權名稱確認其被歸入需要當心一側。

- [x] 2.2 滿足 Licence grant and this project's reuse judgement are shown as separate facts 的分流呈現：授權為明確開放授權者只顯示提供者的宣告、不顯示任何本專案判斷或用法；其餘顯示宣告加上本專案的用法，並指向該筆自身的說明。驗證方式：在頁面上清點兩類的筆數，確認為 20 與 5，並逐筆比對 delta spec 的 Example 表五種情況。

- [x] 2.3 滿足 No verdict of the catalogue's own：目錄【自己產生】的措辭不出現「可再利用」「不可再利用」這類結論。逐筆的原文說明不在此限——那是登記檔的原始文字、作為證據呈現，另有需求要求它完整不改寫，其中可能記載當初如何得出結論。驗證方式：載入頁面後，扣除各筆的原文說明區塊，於其餘文字中搜尋上述字串並確認零命中。

- [x] 2.4 依 design 決策「未填時退回只顯示宣告，不顯示殘缺內容」，滿足 Conduct statement is absent：需要用法敘述而該欄位缺漏時，該筆只顯示提供者的宣告，不顯示佔位文字、不顯示 `reusable` 的值。驗證方式：暫時移除某一筆的該欄位，確認其呈現退回只有宣告且無殘缺文字。

- [x] 2.5 依 design 決策「需要當心的來源在版面上可辨」，該五筆不需展開即可與其餘來源區分。驗證方式：在不展開任何條目的情況下，於頁面上辨識出這五筆並清點其數量。
