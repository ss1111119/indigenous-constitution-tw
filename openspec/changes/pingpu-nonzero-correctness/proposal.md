## Problem

平埔身分登記自 2026-08 中開放，期別 11508（預計 2026-09 初發布）很可能是官方統計中第一期
出現非零平埔人口的資料。站台目前的多處邏輯與文案，前提都是「平埔為 0」，非零之後會產生
錯誤數字或錯誤敘述，而且**都不會報錯**：

1. **席次模擬器重複計算已登記人口。** 模擬器的原住民人口基數累加各縣市 `indigenous_total`，
   而該欄位由轉檔腳本定義為「山地＋平地＋平埔」。滑桿值再加到這個基數上，已登記的平埔人口
   因此被計入兩次。輸出的是席次比例與人口比例，錯了不會有任何異常訊號。

2. **現況基準寫死為零。** 模擬器的參考點文案與說明把「目前官方登記數 0」當成現況陳述。
   非零之後，模擬器宣稱的現況會與人口面板顯示的官方現況互相矛盾。

3. **「首次」宣稱不會自己失效。** 人口面板的已登記狀態固定敘述這是官方統計中首次出現的
   平埔登記人口。11508 成立，11509 之後仍會這樣說。

4. **圖表頁尾的指涉錯誤。** 頁尾宣告「以上各族與未申報合計 N 人，等於原住民人口總數」，
   但 N 包含平埔人數，而平埔在非零時仍呈現於圖表下方的獨立區塊、不在長條之中。
   數字正確，「以上」二字不正確。

5. **沒有非零平埔的成功路徑樣本。** 現有樣本中，平埔兩組結構混加那組的主清單西拉雅確實
   已是非零，但它是刻意失敗的樣本，且其 ODRP013 平埔人口仍為零。其餘成功路徑樣本平埔全為零，
   而全零時所有恆等式無論轉檔讀取哪一組平埔結構都會成立——也就是說現有測試無法分辨
   實作讀對了還是讀錯了。「平埔由 0 變非零且兩來源自洽時一切仍成立」從未被驗證過。

## Root Cause

平埔欄位自 2025-11 起存在但值恆為 0，因此所有依賴「平埔為 0」的假設在過去十個月都成立，
沒有任何測試或執行會揭露它們。第 1 項尤其隱蔽：`indigenous_total` 已含平埔是轉檔腳本的
定義，而模擬器把它當成「不含平埔的現有原住民人口」使用——兩處各自都合理，組合起來才錯。

## Proposed Solution

1. 模擬器的人口基數改為不重複計算：滑桿代表「納入保障體系的平埔人口」，其中已被官方統計
   計入的部分不得再次相加。滑桿語意不變，改變的是起點不再假設為零。

2. 現況基準改由載入的資料導出，不寫死數值。判定依據只用資料本身，與人口面板既有的
   三態判定同一原則（不看日期、不看登記開放日）。

3. 「首次」宣稱限定於確實是第一個非零期別時才成立，否則改為不含時序主張的敘述。

4. 頁尾敘述改為明確涵蓋範圍，使「合計等於原住民人口總數」這句在平埔於長條之外呈現時
   仍然正確。

5. 新增一組非零平埔的回歸樣本，斷言轉檔成功、加總恆等式成立、平埔值進入產出檔、
   且平埔交叉表欄位未被混入。

## Non-Goals

- **不重新設計長條圖。** 平埔非零後是否該從獨立區塊移進長條圖，是呈現形式的設計題；
  現行獨立區塊已能正確呈現數字，且改圖表不影響正確性。列為後續獨立變更。
- **不做平埔登記逐月時序保存。** 需要新的資料保存策略（現行 processed 人口檔為單期覆蓋式），
  屬獨立變更。ODRP 以期別參數提供 2018-01 起各期，資料可事後補抓，不因 11508 而永久遺失。
- **不處理管線中的 absent 三態是否真的可達。** 疑似轉檔時會把缺少的族別欄位補為 0，
  使前端的 absent 分支難以觸發；此為既有資料模型議題，不阻礙 11508 的正確呈現。
- **不調整席次制度模型本身。** 平埔族群併入現行類別或自成一類，法律未定，現行的
  假設呈現方式維持不變。

## Success Criteria

- 在平埔非零的資料下，模擬器初始畫面報出的原住民人口等於人口面板顯示的官方原住民總數，
  且該初始狀態被標示為現況——初始滑桿值為已登記平埔人口，不是零。
- 滑桿為零時報出的人口等於官方總數扣除已登記平埔，且該狀態不被標示為現況，
  因為它代表「不把已登記者納入保障體系」的反事實情境。
- 模擬器不含任何寫死的平埔人口數值作為現況陳述。
- 人口面板在非零平埔下，頁尾的合計敘述所指涉的範圍與實際加總的欄位一致。
- 「首次」宣稱在非第一個非零期別的資料下不出現。
- 回歸測試包含一組非零平埔樣本並全數通過；既有失敗路徑樣本結果不變。

### Modified Capabilities

- `seat-simulator`：現況起點與滑桿參考點兩條需求，需納入「官方統計已計入部分平埔人口」的情況。

- `data-pipeline`：回歸測試需涵蓋非零平埔的成功路徑，現行樣本僅涵蓋失敗路徑與全零成功路徑。
